# Mammoth docs site

[Astro](https://astro.build) + [Starlight](https://starlight.astro.build). Pages
are markdown under `src/content/docs/`; the sidebar is assembled in
`astro.config.mjs`.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # static site into dist/
npm run preview  # serve dist/ as a host would
```

## Writing pages

- Links between pages are **root-relative** — `/concepts/fast-paths/`, never
  `/Mammoth/concepts/fast-paths/`. The base path is added at build time (below).
- Diagrams are ` ```mermaid ` fences in `.md`. In `.mdx`, raw HTML is parsed as
  JSX, so write `<pre class="mermaid">` markup directly instead.
- `src/content/docs/cli/reference.md` is generated by `cargo xtask docs` from
  the clap tree — but that command is a stub until M2, so for now the committed
  file is edited by hand.

## Hosting

The same tree builds for two hosts, controlled by two environment variables:

| Variable | Vercel | GitHub Pages |
| --- | --- | --- |
| `SITE_URL` | unset — the deployment's own domain is used | `https://projectorcha.github.io` |
| `BASE_PATH` | unset — defaults to `/` | `/Mammoth` |

`plugins/rehype-base-links.mjs` prefixes every root-relative link and image in
the rendered HTML when `BASE_PATH` is set, and `src/components/Hero.astro` does
the same for the landing page's frontmatter links, which never reach the
markdown pipeline. With no base set both are no-ops.

### Vercel

Import the repository in the Vercel dashboard and set **Root Directory** to
`web`. Everything else — framework, install and build commands, output
directory — comes from `vercel.json`. No environment variables are required;
set `SITE_URL` only to name a domain other than the project's production one in
the sitemap and canonical URLs.

`vercel.json` also carries an `ignoreCommand` that skips the build when a commit
touched nothing under `web/`. Delete that line to build on every push.

### GitHub Pages

`.github/workflows/pages.yml` builds and deploys on pushes to `main` that touch
`web/`. It is a plain Node build — no Rust toolchain involved.
