title: "E0401 · Checksum mismatch"
---

> **Storage archive.** Mammoth now focuses on [durable context memory for coding agents](/memory/). This page describes the earlier storage project.


Stored bytes or an uploaded checksum do not match the recorded digest.

## What to do

A read automatically tries another replica. Use `mammoth admin repair` to restore damaged copies from a healthy source. If every copy is lost, restore from a backup.
