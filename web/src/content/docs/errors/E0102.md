> **Storage archive.** Mammoth now focuses on [durable context memory for coding agents](/memory/). This page describes the earlier storage project.


This operation received a file where it needed a directory, or a non-empty directory where it needed an empty one.

## What to do

Check `mammoth stat <path>`. Removing a non-empty directory requires an explicit `--recursive` flag.
